# Third-party licences

`index.html` contains a WebAssembly build of code from the projects below,
including the neural-network weights compiled into that code. Their licences
require these notices to accompany binary redistribution.

| Component | Used for | Licence |
|---|---|---|
| [rade_c](https://github.com/freedv/rade_c) — C port of RADE | RADE V1 encoder and decoder, OFDM modulator and receiver, acquisition, end-of-over, filters, network weights | BSD 2-Clause (files carry the notices below) |
| [radae](https://github.com/drowe67/radae) — the RADE reference implementation | origin of the RADE model and algorithms; `verify/loss_np.py` ports its `loss.py` | BSD 2-Clause |
| [Opus](https://opus-codec.org/) 1.5 | speech feature extraction (LPCNet features, PitchDNN), the FARGAN vocoder, and the neural-network runtime | BSD 3-Clause, with royalty-free patent licences |
